### 1. 요약문 (Executive Summary)
> 분량: 1페이지

**Steer의 고유 포지션**:
- 빅테크 에이전트(Claude Cowork, Operator, Mariner)는 **클라우드/브라우저 중심** → Steer는 **로컬 OS 네이티브 (macOS + Windows)**
- Copilot Studio는 **Windows 전용** → Steer는 **macOS/Windows 크로스 플랫폼**
- 기존 RPA(UiPath)는 **고비용·기업 전용** → Steer는 **경량·개인~소기업 대상**
- 레거시 도구(Maestro, Raycast)는 **패턴 학습 없음** → Steer는 **자율 패턴 감지 → 자동화 제안**

| LLM | OpenAI GPT-4 | Claude, Gemini | Function Calling 안정성, 한국어 성능 |

### 5. 핵심 기능 상세
> 분량: 10~13페이지 (**핵심 섹션**)

각 기능을 일관된 구조로 기술:
`목적 → Input → 처리 로직 → Output → 예외 처리 → 스크린샷/결과`

#### 5.1 Shadow (행동 데이터 수집)
- 목적: 사용자 OS 사용 패턴을 자동 수집하여 자동화 기회 발견
- 처리 로직: OS 네이티브 API (macOS: Accessibility / Windows: UI Automation) → PII 마스킹 → SQLite 저장
- 주요 모듈: `collector_pipeline.rs` (SessionEventRow → sessionize → build_session_records)
- **사업적 가치**: 사용자 행동 데이터 기반 인사이트 → B2B 컨설팅 활용 가능

#### 5.2 Routine (패턴 분석 & 자동화 제안)
- 세션 빌드 → 루틴 탐지 → 워크플로우 변환 3단계 파이프라인
- 주요 모듈: `pattern_detector.rs` (Frequent Pattern Mining), `recommendation.rs` / `recommendation_executor.rs` (자동화 제안 생성 및 실행)
- **사업적 가치**: 기업 내 반복 업무를 자동 식별하여 업무 효율화 ROI 산출

#### 5.3 Control (앱 내부 제어)
- macOS: AppleScript/osascript 기반 앱 제어 / Windows: PowerShell/COM 기반 앱 제어
- **Browser Automation**: Accessibility Snapshot 기반 요소 참조 시스템 (ElementRef, Bounds, SnapshotSource)
  - Peekaboo CLI 연동으로 Accessibility Tree 스냅샷 → 요소별 ref_id 부여 → click/hover/type 자동화
- **Visual Driver 폴백**: 스크린 캡처 + LLM 비전 기반 UI 자동화
  - SmartStep (pre_check / post_check 조건 검증)
  - Adaptive UI Wait: 스크린 diff를 계산하여 화면 안정 후 다음 액션 실행
- 주요 모듈: `browser_automation.rs`, `visual_driver.rs`, `applescript.rs`
- **사업적 가치**: B2B SaaS 연동 자동화 (Slack, Notion, Gmail 등)

#### 5.4 Controller (멀티스텝 목표 실행 엔진)
- 목적: 복잡한 자연어 목표를 다단계 계획으로 분해하고, 자율적으로 실행
- **Planner**: 목표 → 액션 시퀀스 생성, 앱 컨텍스트 파싱, 폴백 계획 수립
- **Supervisor**: LLM 기반 계획 검증 (accept / review / escalate)
- **Loop Detector**: 동일 액션 반복 감지 → 무한 루프 방지
- **Heuristics**: 규칙 기반 폴백 (메일 전송, 텍스트 편집 등 특수 시나리오)
- 주요 모듈: `controller/planner.rs`, `controller/supervisor.rs`, `controller/loop_detector.rs`, `controller/heuristics.rs`
- **사업적 가치**: 단순 명령 실행을 넘어 복잡한 업무 자동화 → 엔터프라이즈급 에이전트

#### 5.5 Intent Router (자연어 의도 분류)
- 목적: 사용자 자연어 입력의 의도를 분류하고 필요한 슬롯(파라미터)을 추출
- 지원 의도: 항공권 검색, 쇼핑, 폼 입력, URL 요청 등
- 슬롯 추출: 출발지/도착지 정규화, 날짜 파싱 (상대 날짜 포함), 예산/가격대 파싱
- 주요 모듈: `intent_router.rs`, `nl_automation.rs`, `slot_filler.rs`

#### 5.6 Tool Chaining & Cross-App Bridge
- 목적: 여러 도구/앱 간 데이터를 연쇄적으로 전달하여 복합 시나리오 실행
- **ToolChain**: 다단계 워크플로우 정의 (ToolStep → FailAction: Stop/Continue/Retry/Skip)
- **ExecutionContext**: `{{variable}}` 템플릿 치환으로 이전 도구 결과를 다음 도구에 전달
- **CrossAppBridge**: 클립보드 복사/붙여넣기, 앱 전환, 선택 텍스트 읽기 등 OS 네이티브 브릿지
- 주요 모듈: `tool_chaining.rs`

#### 5.7 Exec (보안 셸 실행)
- 보안 분류: `Safe` / `Warning` / `Critical`
- Write Lock 메커니즘, 타임아웃
- **Approval Gate**: 위험 명령에 대한 사용자 승인 플로우
- 주요 모듈: `bash_executor.rs`, `approval_gate.rs`, `execution_controller.rs`
- **사업적 가치**: 엔터프라이즈 보안 정책 준수 → B2B 도입 장벽 해소

#### 5.8 Workflow (n8n 자동화 생성)
- 자연어 → n8n 워크플로우 JSON 변환 → 자동 배포
- 주요 모듈: `n8n_api.rs`, `workflow_schema.rs`
- **사업적 가치**: No-Code 자동화 시장과의 시너지, 기존 n8n 생태계 활용

#### 5.9 원격 제어 (Telegram)
- Telegram Bot → 자연어 수신 → 실행 → 결과 Markdown 리포트 자동 전송
- 주요 모듈: `telegram.rs`, `integrations/telegram.rs`
- **사업적 가치**: 모바일 원격 제어 → 이동 중에도 업무 자동화 관리

#### 5.10 외부 서비스 통합
- **Google Calendar**: 일정 조회/생성/삭제 (Google OAuth2 인증)
- **Gmail**: 이메일 조회/전송 (Google OAuth2)
- **Notion**: 페이지/데이터베이스 조회/생성
- **MCP (Model Context Protocol)**: Anthropic MCP 규격 준수, JSON-RPC 기반 외부 서비스 연동
  - McpClient (서비스 디스커버리, 도구 호출, 리소스 읽기, 프롬프트 템플릿)
  - McpRegistry (다중 MCP 서버 관리)
- 주요 모듈: `integrations/`, `mcp_client.rs`
- **사업적 가치**: 생태계 확장성, 외부 서비스 연동 → B2B 도입 시 기존 인프라와 통합

#### 5.11 Subagent (멀티에이전트 오케스트레이션)
- 목적: 복잡한 작업을 여러 에이전트에 분배하여 병렬 처리
- SubagentManager: spawn/start/complete/cancel 라이프사이클 관리
- LLM Action Integration: `spawn_agent` 액션 파싱
- 주요 모듈: `subagent.rs`
- **사업적 가치**: 엔터프라이즈 규모의 병렬 업무 자동화 지원

#### 5.12 보안 모델 (Zero Trust Engine)
- PolicyEngine + CommandClassifier + PrivacyGuard 3중 보안
- **Release Gate**: 배포 전 정적/런타임/시맨틱 검증 파이프라인
- **Quality Scorer**: 코드/액션 품질 채점
- 주요 모듈: `policy.rs`, `privacy.rs`, `approval_gate.rs`, `release_gate.rs`, `quality_scorer.rs`
- **사업적 가치**: 기업 보안 규정 준수의 핵심 차별점, B2B 필수 요건 충족
