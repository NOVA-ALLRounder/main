### 1. 도입 + 팀 소개 (2분)

#### Slide 1: 타이틀
- **헤드라인**: Steer — 사용자 행동 기반 자율 학습 AI OS 에이전트
- **서브 카피**: "컴퓨터가 당신의 습관을 학습하고, 스스로 자동화합니다"
- **발표 멘트**: 안녕하세요, 팀 Steer입니다. 저희는 사용자의 행동을 관찰하고 자동화를 제안하는 OS 에이전트를 만들었습니다.

#### Slide 2: 팀 Steer 소개
- **내용**: 팀원별 이름, 담당 역할, 핵심 기여 사항 (1줄씩)
- **발표 멘트**: 저희 팀은 [N]명으로 구성되어 있으며, 각자 Rust 코어, AI 파이프라인, UI/UX, 인프라를 담당했습니다.

> [!IMPORTANT]
> 팀원 이름과 역할을 채워주세요.

#### Slide 3: 문제 정의 — 왜 지금 Steer인가?
- **핵심 메시지**: 기존 자동화 도구의 3대 한계
- **내용**:
  - ❌ **수동 설정**: 사용자가 직접 규칙을 정의해야 함 (UiPath, Zapier)
  - ❌ **플랫폼 제약**: 웹 브라우저만 제어 가능 (OpenAI Operator, Google Mariner)
  - ❌ **높은 비용**: 기업용 RPA 연 수십만 달러, AI 에이전트 구독 월 $200~$20K
- **시장 데이터** (핵심 수치만):
  - 글로벌 RPA 시장: $4.68B (2025) → $25B+ (2030), CAGR ~30%
  - 2025년 기업 AI 에이전트 도입률 72%, 52%가 프로덕션 배포 완료
- **발표 멘트**: 자동화 시장은 폭발적으로 성장 중이지만, 기존 도구들은 여전히 수동적이고, 브라우저에 갇혀 있고, 비쌉니다.

#### Slide 4: Steer의 해결책
- **핵심 메시지**: Steer의 3단 자율 프로세스
- **내용**:
  1. **Shadow** (관찰): OS 사용 패턴을 백그라운드에서 자동 수집
  2. **Routine** (분석): 반복 행동 패턴을 AI가 자율 감지 및 자동화 제안
  3. **Control/Exec** (실행): 자연어 명령으로 OS 전체를 직접 제어
- **차별화**: "설정하지 않아도, 브라우저 밖에서도, OS 전체를 제어합니다."
- **발표 멘트**: Steer는 세 단계로 동작합니다. 먼저 사용자의 행동을 관찰하고, 반복 패턴을 스스로 발견한 뒤, 자연어 한마디로 OS 전체를 제어합니다.

> **전환**: "이제 이 프로세스를 가능하게 하는 기술 구조를 보여드리겠습니다."

### 2. 기술 및 시스템 설계 (3분)

#### Slide 5: 핵심 기술 스택
- **핵심 메시지**: 각 기술 선택의 이유를 한 줄로
- **내용**:

| 기술 | 역할 | 선택 이유 |
|------|------|----------|
| **Rust** | 코어 엔진 | 메모리 안전, 단일 바이너리, OS 네이티브 바인딩 |
| **GPT-4** | 자연어 이해 | Function Calling 안정성, 한국어 성능 |
| **Tauri** | 데스크톱 UI | Electron 대비 1/10 번들, Rust 직접 통합 |
| **n8n** | 워크플로우 | 셀프호스팅, 커뮤니티 생태계, API 유연성 |
| **SQLite** | 로컬 DB | 서버리스, 로컬 에이전트에 최적 |

- **발표 멘트**: 핵심은 Rust입니다. C++ 수준의 성능과 메모리 안전성을 갖추면서 macOS/Windows 양쪽 네이티브 API에 직접 바인딩합니다.

#### Slide 6: 시스템 아키텍처
- **핵심 메시지**: 전체 데이터 흐름을 한눈에
- **내용 (간략화된 아키텍처)**:
  ```
  사용자 입력 (Desktop UI / Telegram / CLI)
       ↓
  API Server (Axum) → LLM Gateway (GPT-4)
       ↓
  Policy Engine (Zero Trust 보안 검증)
       ↓
  Executor (macOS: AppleScript / Windows: PowerShell)
       ↓
  Collector → SQLite → Pattern Analyzer → n8n 배포
  ```
- **강조 포인트**: LLM 출력이 직접 실행되지 않고, 반드시 Policy Engine의 보안 검증을 거친다는 점
- **발표 멘트**: 주목할 점은 LLM이 생성한 명령이 절대 직접 실행되지 않는다는 것입니다. 모든 액션은 반드시 Policy Engine의 보안 검증을 거칩니다.

#### Slide 7: 크로스 플랫폼 & 데이터 보안
- **핵심 메시지**: macOS + Windows 동시 지원 및 개인정보 보호
- **내용**:
  - **macOS**: Accessibility API 이벤트 수집 + AppleScript 앱 제어
  - **Windows**: UI Automation API 수집 + PowerShell/COM 앱 제어
  - **보안 3중 장치**: PrivacyGuard(PII 마스킹) → PolicyEngine(위험 분류) → WriteLock(Critical 차단)
- **발표 멘트**: Steer는 macOS와 Windows 양쪽에서 동일한 경험을 제공하며, 수집 데이터의 개인정보는 실시간 마스킹됩니다.

> **전환**: "이제 실제로 어떻게 작동하는지 시연 영상으로 보여드리겠습니다."

### 3. 핵심 기능 시연 (6분)

> 시연 영상을 4개 파트로 나누어 촬영/편집합니다. 각 파트 앞에 간략한 설명을 먼저 하고, 영상을 재생하는 방식입니다.

#### Slide 8: 시연 1 — Shadow & Routine (2분)
- **시나리오**: "매일 아침 같은 앱 3개를 열고 같은 작업을 반복하는 사용자"
- **시연 흐름**:

| 순서 | 화면 | 동작 | 설명 |
|------|------|------|------|
| 1 | 데스크톱 | 사용자가 평소처럼 앱 사용 | Shadow가 백그라운드에서 이벤트 수집 중 |
| 2 | 터미널/UI | `collector` 실행 상태 확인 | 이벤트가 SQLite `events_v2` 테이블에 저장됨을 보여줌 |
| 3 | 터미널/UI | `build_sessions` → `build_routines` 실행 | 이벤트 → 세션화 → 반복 패턴(루틴) 후보 감지 |
| 4 | 터미널/UI | LLM이 루틴 분석 결과 요약 + "자동화할까요?" 제안 | 패턴 → 워크플로우 제안까지의 자율적 흐름 |
| 5 | n8n 대시보드 | 자동 생성된 워크플로우 확인 | 제안이 실제 n8n에 배포되어 실행 가능 상태 |

- **핵심 한마디**: "사용자가 아무것도 설정하지 않아도, 에이전트가 스스로 패턴을 발견합니다."

#### Slide 9: 시연 2 — Control: 자연어 앱 제어 (1.5분)
- **시나리오**: "자연어 한 마디로 여러 앱을 연쇄 조작"
- **시연 흐름**:

| 순서 | 화면 | 동작 | 설명 |
|------|------|------|------|
| 1 | Steer UI/CLI | 사용자가 자연어 입력: "Safari 열어서 날씨 검색해" | 자연어 → LLM Gateway → Function Calling |
| 2 | 데스크톱 | Safari 자동 실행 → 검색창 클릭 → "날씨" 입력 | AppleScript/PowerShell을 통한 OS 네이티브 제어 |
| 3 | Steer UI/CLI | 더 복잡한 명령: "Slack 열고 #general에 '회의 시작' 보내" | 멀티 앱 연쇄 제어 시연 |
| 4 | 데스크톱 | Slack 앱 실행 → 채널 이동 → 메시지 입력 → 전송 | LLM이 여러 단계를 계획하고 순차 실행 |

- **핵심 한마디**: "자연어 한마디로 실제 OS와 앱을 직접 제어합니다."

#### Slide 10: 시연 3 — Workflow & Exec: 보안 자동화 (1.5분)
- **시나리오**: "셸 명령 실행 시 보안 등급에 따른 차등 처리"
- **시연 흐름**:

| 순서 | 화면 | 동작 | 설명 |
|------|------|------|------|
| 1 | Steer UI/CLI | "내 다운로드 폴더 정리해줘" 입력 | 자연어 → LLM이 셸 명령 생성 |
| 2 | 터미널 | PolicyEngine이 `ls ~/Downloads` → **Safe** 분류 | 읽기 전용 명령 = 즉시 실행 |
| 3 | Steer UI/CLI | "오래된 파일 삭제해줘" 입력 | LLM이 `rm` 명령 생성 |
| 4 | 터미널 | PolicyEngine 이 `rm` → **Critical** 분류 → WriteLock 활성화 | 삭제 명령 = 사용자 확인 요구 |
| 5 | Steer UI/CLI | 사용자가 승인 → 실행 완료 | 보안을 지키면서도 자동화 달성 |

- **핵심 한마디**: "자동화를 만들면서도 보안은 절대 타협하지 않습니다."

#### Slide 11: 시연 4 — Telegram 원격 제어 (1분)
- **시나리오**: "외출 중 모바일에서 내 컴퓨터 제어"
- **시연 흐름**:

| 순서 | 화면 | 동작 | 설명 |
|------|------|------|------|
| 1 | 모바일 (Telegram) | 사용자가 봇에 명령 전송: "오늘 수집 통계 보여줘" | Telegram Bot API → Steer 서버 수신 |
| 2 | 데스크톱 (백그라운드) | Steer가 명령 처리 → `/stats` API 호출 | 로컬 머신에서 실제 실행 |
| 3 | 모바일 (Telegram) | 실행 결과가 Markdown으로 자동 리포트 | 결과를 깔끔하게 포맷팅하여 전송 |

- **핵심 한마디**: "어디서든, 언제든, 내 컴퓨터를 안전하게 제어할 수 있습니다."

> **전환**: "이 기술을 어떻게 사업화할 수 있을까요?"

### 4. 비즈니스 및 미래 (3분)

#### Slide 12: 경쟁 분석 & 시장 포지셔닝
- **핵심 메시지**: Steer만의 Blue Ocean 영역
- **내용 (핵심 경쟁사 4개만 비교)**:

| 경쟁사 | 한계 | Steer 차별점 |
|--------|------|-------------|
| Claude Cowork | 클라우드 의존, OS 제어 불가 | ✅ 로컬 OS 네이티브 제어 |
| OpenAI Operator | 웹 브라우저 전용 | ✅ OS 전체 제어 |
| Microsoft Copilot | Windows 전용, 고비용 | ✅ macOS+Windows, 경량 |
| UiPath (레거시) | 고비용, LLM 미통합 | ✅ LLM 네이티브 + 자율 학습 |

- **포지셔닝 한 줄**: "로컬 OS 네이티브 + LLM 자연어 + 자율 패턴 학습 — 세 가지를 모두 갖춘 유일한 에이전트"
- **발표 멘트**: 빅테크 에이전트들은 클라우드나 브라우저에 한정되어 있고, 레거시 RPA는 비싸고 LLM이 없습니다. Steer는 이 빈 공간을 정확히 겨냥합니다.

- **내용**:

|------|------|----------|------|
| **Free** | 개인 | 기본 셸 실행, 5회/일 LLM | 무료 |
| **Pro** | 파워 유저 | 무제한 LLM, 패턴 분석, Telegram | $9.9/월 |

- **발표 멘트**: 개인 사용자에게는 무료로 제공하여 커뮤니티를 확보하고, 고급 기능을 원하는 파워 유저와 기업 고객으로 확장하는 전략입니다.

#### Slide 14: 향후 로드맵

- **비전**: "궁극적으로 Steer는 모든 OS에서 동작하는 자율형 AI 비서가 되는 것을 목표로 합니다."

| # | 파트 | 소요 | 촬영 환경 | 준비 사항 |
|---|------|------|----------|----------|
| 1 | Shadow & Routine | 2분 | macOS 또는 Windows | Shadow 데이터 최소 1일치 사전 수집, `build_sessions` / `build_routines` 실행 준비, n8n Docker 가동 |
| 2 | Control | 1.5분 | macOS 또는 Windows | 시연 앱(Safari/Chrome, Slack) 사전 로그인, Steer API 서버 실행 확인 |
